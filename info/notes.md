### start dev server to connect to emulator 
```
npx react-native start
```
this will start a metro bundler that acts like a local web server, and streams JS code to the emulator in real time 

### build app (dev build)
```
npx react-native run-android
```

this will build the app and connect it to the metro bundler, allowing you to debug your app 

when to build
- new packages installed
